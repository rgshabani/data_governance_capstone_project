# Best practices while development

1. Please ensure that when creating jobs as yml file under "notebook_task" to include also those lines since those represent the necessery information to know in the future how the pipeline was executed.

```
base_parameters:
    pipeline_id: "{{job.id}}"
    run_id: "{{job.run_id}}"
    task_id: "{{task.run_id}}"
    processed_timestamp: "{{job.start_time.iso_datetime}}"
    catalog: "${var.catalog}"
```
If using scripts put this under "spark_python_task"

```
parameters:
    - "{{job.id}}"
    - "{{job.run_id}}"
    - "{{task.run_id}}"
    - "{{job.start_time.iso_datetime}}"
    - "${var.catalog}"
```
2. Please ensure that when creating tables at bronze, silver or gold to include also the below code so the tables have the neccesery metadatainformation:

```
pipeline_id = dbutils widgets-get("pipeline_id")
run_id = dbutils. widgets. get(" run_id")

```

or if using scripts

4. While using importing the modules there may ocur errors due to how the system variables are setup in VS Code and Databricks. To eliminate those problems you can use the code below in each of the scripts or notebooks or the better solution is creating a python wheel.

```
import os 
import sys

current_dir = os.getcwd()
projectroot = os. path. abspath(os.path.join(current_dir, ".", "…", "…"))

sys.path.append(projectroot)
```

To create a wheel plese ensure you have the build instelled if not just run the below command:
```
pip3 install build
```

After that create the wheel with the folowing command

```
python3 -m build
```

After this command has been executed with success you should have 2 new directories "build" and "dist" specifically.
Then run the following command to include your wheel as a package

```
pip3 install dist/<wheel_name>
```

If however the wheel exists and is included as a package run the following command:

```
rm -rf build/ dist/ *.egg-info/
```

Build the wheel again

```
python3 -m build
```

And upgrade the package
```
pip3 install --upgrade dist/<wheel_name>
```


Or you can create a wheel job by including a task at beginning of the pipeline as following:

1. You add a folder under the src which you want to declare the main function
2. Make it a package by including the ```__init__.py```
3. Add a main file with a main function
4. 
```
- task_key: <task_name> 
    python_wheel_task:
        package_name: <name of the package under which main is declared under the src folder> 
    entry_point: main
    job_cluster_key: <the job_cluster_key you want to use>
    libraries:
        - whl: <relative path in your of your project in your local machine or all of the wheel files as <../dist/*.whl>>
```
